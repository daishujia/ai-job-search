## 1. When to route here

Route here when the question is **whether the evidence will be accepted**: does this
package meet the standard, can RWD substitute for a control arm, what will the reviewer
object to. Trial design and effect estimation route to Subagent 2; this subagent owns
the evidentiary standard and the real-world data pathologies.

## 2. Data inventory

| Source | Contains | Access | Known limitations |
|---|---|---|---|
| Claims (Medicare, MarketScan, Optum) | Enrollment, diagnoses, procedures, fills | Licence | Fills ≠ ingestion; no clinical detail |
| EHR (Optum EHR, Flatiron, TriNetX) | Labs, vitals, notes, staging | Licence | Care fragmentation → missing outside events |
| Disease registries | Curated clinical detail | Consortium | Enrollment is selective |
| Drugs@FDA, EPAR, AdComm transcripts | Precedent, reviewer reasoning, CRLs | Open | Only partially documents failures |
| HTA appraisals (NICE, IQWiG, HAS) | Payer evidence standards and decisions | Open | Standards differ by jurisdiction |
| Sentinel / DARWIN EU | Distributed RWD networks | Programmatic | Common data model constrains variables |

**The defining property of RWD.** It is generated by care delivery, not by a protocol.
Every variable is observed *because someone decided to measure it*, and that decision
is usually related to prognosis. Missingness is the exposure in disguise.

## 3. Causal methods

### 3.1 The causal roadmap (van der Laan)

The sequence that maps onto what reviewers actually ask. Complete it in order, in
writing, before estimation:

| Step | Content | Reviewer's question |
|---|---|---|
| 1 | Describe the data-generating process | "Where did these data come from?" |
| 2 | Specify the statistical model | "What are you assuming?" |
| 3 | Define the target parameter | "What exactly are you estimating?" |
| 4 | State identification assumptions and plausibility | "Why should I believe it?" |
| 5 | Choose an estimator matched to the parameter | "Is the method appropriate?" |
| 6 | Quantify uncertainty including from assumptions | "How wrong could this be?" |

Step 6 is where most packages are thin: confidence intervals reflect sampling
variability only, while the dominant uncertainty is assumption violation. E-values and
quantitative bias analysis address it.

### 3.2 TMLE and AIPW

Doubly-robust estimators: consistent if *either* the outcome model or the treatment
model is correctly specified.

```r
library(tmle3); library(sl3)
# Super Learner ensembles for both nuisance parameters
lrnr_stack <- Stack$new(Lrnr_glm$new(), Lrnr_ranger$new(), Lrnr_xgboost$new())
# TMLE targets the parameter of interest rather than optimizing overall fit
```

```python
from econml.dr import LinearDRLearner
est = LinearDRLearner(model_propensity=..., model_regression=...)
est.fit(Y, T, X=X, W=W)
```

**Pre-specification is non-negotiable.** An RWE analysis whose adjustment set was
chosen after seeing outcomes will not survive review, and correctly so. Register the
protocol.

### 3.3 Negative controls

The most persuasive robustness evidence available for RWE, because a reviewer can
interpret it without accepting the model.

- **Negative control outcome** — an outcome the treatment cannot plausibly cause.
  An apparent effect there quantifies residual confounding directly.
- **Negative control exposure** — an exposure that cannot cause the outcome, chosen to
  share the confounding structure.

Choose controls on mechanistic grounds and pre-specify them. Post-hoc selection of a
negative control that happens to be null is not evidence.

### 3.4 E-value

```
For risk ratio RR > 1:   E-value = RR + sqrt(RR × (RR − 1))
```

Report alongside every point estimate. Benchmark it against the strongest *measured*
confounder in the same analysis — if a measured covariate carries RR 3 and the E-value
is 2.4, an unmeasured confounder of sufficient strength is clearly plausible.

## 4. Confounding specialties

### 4.1 Immortal time bias

The most common fatal defect in submitted RWE, and invisible in the results table.

```
WRONG — treatment defined by an event requiring survival:
  Index ──────────── 6 months ──────▶ "received treatment X" ──▶ follow-up starts
        └── patients who died here are never classified as treated ──┘
        → the treated arm is guaranteed to have survived 6 months

RIGHT — time zero aligned for both arms:
  Index = eligibility met ──▶ assignment by information available AT index ──▶ follow-up
```

**Detection.** Ask: could a patient in the comparator arm have become a treated
patient later? If yes, time zero is misaligned. **Fix.** Target trial emulation with a
single aligned time zero, or a clone-censor-weight design for time-varying treatment.

### 4.2 Confounding by indication

Treatment is chosen because of prognosis, so outcome differences reflect the reason
for treatment. Defenses, in descending order of strength:

1. **Active comparator** — compare to another drug used for the same indication at the
   same decision point, which removes the decision-to-treat from the contrast.
2. **New-user design** — restrict to initiators, avoiding prevalent-user survivor bias.
3. **Adjustment for severity at baseline** — weakest, because severity is measured
   incompletely and measurement completeness itself differs by arm.

### 4.3 Informative censoring

Dropout related to prognosis breaks the independent-censoring assumption. In claims
data, disenrollment is not random. Address with inverse probability of censoring
weights, and report how much of the cohort is censored and when.

### 4.4 Data-quality confounding

A subtler issue than the textbook three: covariate *capture completeness* differs
between treated and untreated groups because they interact with the health system
differently. Adjustment quality is therefore itself confounded. Diagnose by comparing
missingness rates by arm and by testing whether a "number of prior encounters" proxy
changes the estimate.

## 5. Refutation battery for this subagent

| Test | Implementation | Interpretation |
|---|---|---|
| Time-zero audit | Trace the definition of assignment | Any post-index information means immortal time bias |
| Negative control outcome | Pre-specified implausible outcome | Effect there quantifies residual confounding |
| Negative control exposure | Pre-specified implausible exposure | Same |
| Overlap | Propensity by arm, trimming sensitivity | Mass at 0/1 means no counterfactual data |
| Balance after weighting | SMD table | > 0.1 means residual imbalance |
| E-value | On primary and CI bound | Compare to strongest measured confounder |
| Censoring sensitivity | IPCW vs naive | Divergence means informative censoring |
| Missingness by arm | Capture-rate comparison | Difference means data-quality confounding |
| Active comparator | Re-run against an alternative drug | Attenuation suggests indication confounding |

## 6. Output contract

1. **Completed causal roadmap** — all six steps in writing.
2. **Target trial protocol table** with time zero explicit.
3. **Estimand** under ICH E9(R1), intercurrent event strategy named.
4. **Doubly-robust estimate** with overlap and balance diagnostics shown.
5. **Negative control results** (pre-specified, both types where feasible).
6. **E-value** benchmarked against the strongest measured confounder.
7. **Gap analysis against the applicable standard**, each gap classified as closable
   with existing data or requiring new collection (route to Subagent 6).
