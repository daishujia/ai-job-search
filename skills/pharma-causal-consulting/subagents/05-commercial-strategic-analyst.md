## 1. When to route here

Route here when the question is **did our action work, and where should we act next**:
campaign attribution, launch performance, targeting, portfolio prioritization. Market
*sizing* and deal-flow structure route to Subagent 1; this subagent owns intervention
effects on commercial outcomes.

## 2. Data inventory

| Source | Contains | Access | Known limitations |
|---|---|---|---|
| Prescription panels (IQVIA, Symphony) | Scripts by HCP, geography, time | Licence | Projection methodology varies by market |
| Sales / shipment data | Volume, gross and net revenue | Internal | Channel inventory distorts short windows |
| Promotional activity logs | Calls, samples, digital touches, timing | Internal (CRM) | Logged intent ≠ delivered contact |
| Formulary / payer coverage | Tier, restriction, effective dates | Licence + public | Effective vs announced date differ |
| Competitor launch timing | Entry dates, indications | Public | Soft launches are hard to date |
| Portfolio financials | Spend, forecast, realized revenue | Internal | Forecast vintages are often overwritten |

**Preserve forecast vintages.** Overwriting forecasts destroys the only data that can
test whether forecasting works. Archive each vintage with its date — it is the input
to the circularity and calibration tests.

## 3. Causal methods

### 3.1 Uplift modeling

The commercial question is not who responds but who responds *because of* the
intervention.

```python
from causalml.inference.meta import BaseXRegressor
from xgboost import XGBRegressor

learner = BaseXRegressor(learner=XGBRegressor(max_depth=4, n_estimators=400))
cate = learner.fit_predict(X=X, treatment=T, y=Y)   # rank by cate, not by P(response)
```

| Segment | Behavior | Action |
|---|---|---|
| Persuadables | Act only if treated | **Target these** |
| Sure things | Act regardless | Do not spend |
| Lost causes | Never act | Do not spend |
| Sleeping dogs | Act only if *not* treated | **Targeting destroys value** |

A response model cannot separate persuadables from sure things, which is why
response-ranked targeting systematically overstates its own ROI. Report all four
segments with their sizes.

### 3.2 Geographic DiD

Staggered rollout across territories is the workhorse design.

```r
library(did)
att <- att_gt(yname = "scripts", tname = "period", idname = "territory",
              gname = "first_treated_period", xformla = ~ baseline_volume,
              data = panel, control_group = "notyettreated")
aggte(att, type = "dynamic")   # event-study path
```

Use Callaway–Sant'Anna rather than two-way fixed effects: with staggered adoption, TWFE
uses already-treated units as controls with weights that can be negative, so the
estimate need not lie within the range of the underlying effects.

**Interference is the standing threat.** Sales-force reallocation and competitor
response cross territory boundaries, violating SUTVA. Define units large enough to
contain spillover, or model it explicitly and report the assumed spillover radius.

### 3.3 Counterfactual scenario modeling

Build "World A vs. World B" comparisons where both worlds are generated by the same
estimated model under different interventions, so the comparison is internally
consistent. Each scenario states: the intervention, the assumptions it relies on, the
predicted outcome with an interval, and the observable that would falsify it.

A scenario without a falsifier is a narrative, not an analysis.

## 4. Confounding specialties

### 4.1 Self-selection in promotional targeting

```
   Market potential (unobserved) ──┬──▶ Promotional targeting
                                   └──▶ Prescriptions
```

Reps call on high-potential prescribers. Naive comparison of called versus non-called
attributes their potential to the calls, biasing the effect upward — mechanically, not
marginally. This is why reported promotional ROI is nearly always overstated.

**Handling.** Exploit rollout timing as quasi-randomization; use territory-level DiD
where assignment is administrative rather than potential-driven; or run a holdout,
which remains the only clean answer and is worth arguing for.

### 4.2 Goodhart's Law in forecasting

Once a metric becomes the target, it decouples from the construct it measured. A sales
target set on script volume changes the mix of behaviors generating scripts, so the
historical relationship between scripts and revenue stops holding.

**Diagnostic.** Monitor the measure–construct gap: track both the targeted metric and
an untargeted proxy for the same construct. Divergence between them is the signature.

### 4.3 Reflexivity

The forecast changes the behavior it forecasts. A bullish forecast justifies sales-force
expansion, which raises sales, which appears to validate the forecast. As with
circularity, the model cannot be wrong, which means it is not informative.

**Handling.** Hold out a region from the resourcing decision where feasible, and always
backtest forecasts against realized outcomes by vintage.

### 4.4 Selection on the dependent variable

Analyzing only successful launches to learn what causes success conditions on the
outcome. Reconstruct the full cohort of launches, including the failures, before
computing any rate.

## 5. Refutation battery for this subagent

| Test | Implementation | Interpretation |
|---|---|---|
| Pre-trend | Event-study leads | Non-zero leads invalidate DiD |
| Placebo-in-time | Fake treatment date pre-period | Effect means confounding |
| Placebo-in-space | Untreated territories | Effect means secular trend |
| Uplift validation | Qini / uplift curve on held-out data | Flat curve means no real heterogeneity |
| Sleeping-dog check | Negative-CATE segment size | Non-trivial size changes the recommendation |
| Spillover sensitivity | Vary the unit / exclude borders | Large shifts mean interference |
| Forecast backtest | Prior vintages vs realized | The reflexivity and circularity test |
| Measure–construct gap | Targeted vs untargeted proxy | Divergence means Goodhart |
